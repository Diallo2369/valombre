# Images de « Les Brumes de Valombre » pour ChatGPT

58 images, dans l’ordre où on les découvre en jouant. Commencez par le chapitre 1 : c’est ce que les enfants voient en premier.

## Comment faire

1. Ouvrez **une seule conversation** ChatGPT pour toutes les images (le style restera cohérent, et les personnages garderont le même visage).
2. Envoyez d’abord les deux messages d’ouverture ci-dessous : le style, puis les règles de fichier.
3. Puis, pour chaque image : collez le prompt, téléchargez le résultat.
4. Vérifiez que le fichier reçu porte bien le nom de la ligne « Fichier : » et finit par `.webp`. Sinon : « Renomme le fichier exactement comme indiqué dans la ligne Fichier, au format WebP. »
5. Dans l’atelier (`/atelier`), sur la fiche de l’image, cliquez sur **« ⬆ Déposer le fichier »** (ou déposez-le directement dans `public/medias/brumes-de-valombre/`).
6. Prévenez Claude : il regardera les images et recalera les lumières vivantes (feu, lanternes, lueurs) au bon endroit.

Astuce : si un personnage revient (Berthe, Pff…), dites « même personnage que dans l’image de … » pour garder son visage.

## Message 1 : le style (à envoyer en premier)

```
Je vais te demander une série d’illustrations pour un conte interactif destiné à des enfants de 8 à 12 ans. Toutes les images de cette conversation doivent suivre exactement le même style :
Illustration peinte numérique façon livre de contes sombre pour enfants de 8 à 12 ans, mélange d’aquarelle et de gravure à l’encre, palette bleu nuit, gris brume et lumières ambrées chaudes, contrastes doux, aucun sang ni gore, aucune créature terrifiante (inquiétante au plus), aucun texte ni lettrage dans l’image.
Les personnages qui reviennent d’une image à l’autre gardent le même visage, les mêmes vêtements et les mêmes couleurs.
Réponds seulement « Compris ».
```

## Message 2 : les règles de fichier (à envoyer juste après)

```
Deux règles valent pour toutes les images de cette conversation, sans exception :
1. Nom du fichier : chaque prompt commence par une ligne « Fichier : … ». Le fichier que tu me donnes doit porter impérativement ce nom, à l’identique, sans rien ajouter ni modifier (pas de suffixe, pas de numéro, pas d’espace).
2. Format : WebP uniquement. Si l’image est créée dans un autre format, convertis-la en WebP avant de me la donner.
Ce nom de fichier est celui que le jeu utilise : un nom différent, et l’image ne s’affiche pas.
Réponds seulement « Compris ».
```
